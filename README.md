# dsh-cust-search

Pre-built distribution package for **dsh-cust-search** (Multi-Engine Sequential Fallback Custom Web Search plugin for DeepSeek Harness WebUI).

For full documentation, screenshots, and source code, visit the GitHub repository:

👉 **https://github.com/u9521/dsh-cust-search**

## Quick Install

```sh
dsh plugin --profile web add github:u9521/dsh-cust-search#dist
```

Then restart web (`dsh web`) and hard-refresh your browser (Cmd+Shift+R).
